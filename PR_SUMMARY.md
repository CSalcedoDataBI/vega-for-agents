# Adopt 11 Vega / Vega-Lite authoring traps from issue #20

Adds `exports/adopted-traps.catalog.json`, generated by `scripts/extract_catalog.py` from
`scripts/adopted_traps.py`. Each trap carries a stable `id`, its `language`, a `symptom`, a `cause`,
a `fix`, and the `status` of its deduplication against the existing draft notes.

The name catalogues (`exports/vega-*.catalog.json`), the expression catalogue and the event-stream
catalogue contain no trap entries, so deduplication was against `reference/drafts/`. Five traps
were already covered there and were merged into those notes; six are new notes. No trap was
rejected.
