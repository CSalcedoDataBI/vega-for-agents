# Event streams — Vega

> Generated by `scripts/extract_catalog.py` from the Vega 6.4.0 source and docs (`adf0ae7`, BSD-3-Clause). Do not edit by hand.

An event stream is what a signal handler listens to (`"on": [{"events": …}]`). It is written as an object, as a selector string, or as a signal or scale reference. The JSON Schema types the selector as a free string; this card is the grammar Vega actually parses.

## Selector string

General form: `(source:)?type([filter])*({throttle(,debounce)?})?`

| Piece | Syntax |
|---|---|
| merge several streams | `,` |
| source before the type | `:` |
| mark name prefix | `@` |
| filter (one or more, combined with and) | `[expression]` |
| between two streams | `[start, stop] > stream` |
| throttle and debounce, in ms | `{throttle,debounce}` |
| consume (`preventDefault`), after the type | `!` |

## Sources

Default source: `view` (`scope` inside a nested group). Named sources: `*`, `view`, `scope`, `window`, `container`. A mark type or `@markname` before the colon restricts the stream to those marks. Anything else before the colon is read as a CSS selector for DOM elements outside the view.

Mark types the parser recognises: `*`, `arc`, `area`, `group`, `image`, `line`, `path`, `rect`, `rule`, `shape`, `symbol`, `text`, `trail`.

## Event types

On marks, the view and the scope: `click`, `dblclick`, `dragenter`, `dragleave`, `dragover`, `keydown`, `keypress`, `keyup`, `mousedown`, `mousemove`, `mouseout`, `mouseover`, `mouseup`, `mousewheel`, `touchend`, `touchmove`, `touchstart`, `wheel`.

- `timer`: fires every `throttle` milliseconds; source ignored.
- `resize` on the `container` source (since Vega 6.4).

Other DOM sources (`window`, a CSS selector) take any event type the browser fires there.

## Event stream object

| Property | Type | Required | Description |
|---|---|---|---|
| `source` | String |  | The input event source. For event streams defined in the top-level scope of a Vega specification, this property defaults to `"view"`, which monitors all input events in the current Vega view component (including those targeting the containing Canvas or SVG component itself). For event streams defined within nested scopes, this property defaults to `"scope"`, which limits consideration to only events originating within the group in which the event stream is defined. Othe legal values include `"window"` for the browser window object, `"container"` for the DOM element containing the view (`"resize"` events only), or a [CSS selector](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Selectors) string indicating external DOM elements. The source property is ignored if the event _type_ is `"timer"`. |
| `type` | String | yes | The event type to monitor (e.g., `"click"`, `"keydown"`, `"timer"`). For more, see the [supported event types list](https://vega.github.io/vega/docs/event-streams/#types). |
| `between` | [EventStream](https://vega.github.io/vega/docs/event-streams/#object)[] |  | A two-element array of event stream objects, indicating sentinel starting and ending events. Only events that occur between these two events will be captured. |
| `consume` | Boolean |  | A boolean flag (default `false`) indicating if this stream should consume the event by invoking [`event.preventDefault()`](https://developer.mozilla.org/en-US/docs/Web/API/Event/preventDefault). To control event consumption more globally, see the [event handling configuration](https://vega.github.io/vega/docs/config/#events). |
| `filter` | [Expression](https://vega.github.io/vega/docs/expressions) \| [Expression](https://vega.github.io/vega/docs/expressions)[] |  | One or more filter expressions, each of which must evaluate to a truthy value in order for the event to be captured. These expressions may **not** reference signal values, only event properties. |
| `debounce` | Number |  | The minimum time to wait between event occurrence and processing. If a new event arrives during a debouncing window, the debounce timer will restart and only the new event will be captured. |
| `markname` | String |  | The unique name of a mark set for which to monitor input events. Events originating from other marks will be ignored. |
| `marktype` | String |  | The type or marks (`arc`, `rect`, _etc._) to monitor for input events. Events originating from other mark types will be ignored. |
| `throttle` | Number |  | The minimum time in milliseconds between captured events (default `0`). New events that arrive within the throttling window will be ignored. For timer events, this property determines the interval between timer ticks. |
| `stream` | [EventStream](https://vega.github.io/vega/docs/event-streams/#object) | yes | An input event stream to modify with additional parameters. |
| `merge` | [EventStream](https://vega.github.io/vega/docs/event-streams/#object)[] | yes | An array of event streams to merge into a single stream. |

`stream` (a derived stream) and `merge` are each required only in their own form of the object.

## References

- Signal reference: `{"signal": "…"}` fires when that signal changes.
- Scale reference: `{"scale": "…"}` fires when that scale changes.

## Examples, as the parser reads them

`mousedown` — capture all mousedown events, regardless of source

```json
[{"source": "view", "type": "mousedown"}]
```

`*:mousedown` — mousedown events on marks, but not the view itself

```json
[{"source": "view", "type": "mousedown", "marktype": "*"}]
```

`rect:mousedown` — mousedown events on any rect marks

```json
[{"source": "view", "type": "mousedown", "marktype": "rect"}]
```

`@foo:mousedown` — mousedown events on marks named 'foo'

```json
[{"source": "view", "type": "mousedown", "markname": "foo"}]
```

`symbol:mousedown!` — capture and consume mousedown events on symbol marks

```json
[{"source": "view", "type": "mousedown", "marktype": "symbol", "consume": true}]
```

`window:mousemove` — capture mousemove events from the browser window

```json
[{"source": "window", "type": "mousemove"}]
```

`container:resize` — capture size changes of the view container element

```json
[{"source": "container", "type": "resize"}]
```

`mousemove{100}` — throttle the stream by 100 ms

```json
[{"source": "view", "type": "mousemove", "throttle": 100}]
```

`mousemove{100, 200}` — also debounce the stream by 200 ms

```json
[{"source": "view", "type": "mousemove", "throttle": 100, "debounce": 200}]
```

`mousemove{0, 200}` — debounce by 200 ms, but do not throttle

```json
[{"source": "view", "type": "mousemove", "debounce": 200}]
```

`timer{1000}` — capture a timer tick every 1000 ms

```json
[{"source": "view", "type": "timer", "throttle": 1000}]
```

`mousemove[event.buttons]` — mousemove events with any mouse button pressed

```json
[{"source": "view", "type": "mousemove", "filter": ["event.buttons"]}]
```

`click[event.shiftKey]` — click events with the shift key pressed

```json
[{"source": "view", "type": "click", "filter": ["event.shiftKey"]}]
```

`path:mousedown, path:touchstart`

```json
[{"source": "view", "type": "mousedown", "marktype": "path"}, {"source": "view", "type": "touchstart", "marktype": "path"}]
```

`[rect:mousedown, window:mouseup] > window:mousemove`

```json
[{"source": "window", "type": "mousemove", "between": [{"source": "view", "type": "mousedown", "marktype": "rect"}, {"source": "window", "type": "mouseup"}]}]
```
