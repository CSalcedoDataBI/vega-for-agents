## `containerSize`

`containerSize()`  

Returns the current CSS box size (`[el.clientWidth, el.clientHeight]`) of the parent DOM element that contains the Vega view. If there is no container element, returns `[undefined, undefined]`. To keep a view sized to its container, update a size signal on the [`container:resize`](https://vega.github.io/vega/docs/event-streams/#types) event stream. (since Vega 6.4)

## `screen`

`screen()`  

Returns the [`window.screen`](https://developer.mozilla.org/en-US/docs/Web/API/Window/screen) object, or `{}` if Vega is not running in a browser environment.

[Vega docs](https://vega.github.io/vega/docs/expressions/#screen) · defined in `packages/vega-functions/src/codegen.js`

## `windowSize`

`windowSize()`  

Returns the current window size (`[window.innerWidth, window.innerHeight]`) or `[undefined, undefined]` if Vega is not running in a browser environment.
